# Verdant GIS V14.3 — UI / Checkout / Map Polish

This release contains only the requested frontend changes.

## Changed
1. Hero world-map markers now use real geographic coordinates so labels/markers align with the correct regions.
2. Successful paid and free checkout completion redirects the customer to `/dashboard`.
3. Map feature clicks now show one Leaflet feature-information popup only. The duplicate right-side feature panel was removed.
4. Attribute control and attribute table modal were visually polished.
5. Cart and checkout containers, cards, spacing, summary panels and buttons were visually refined.

## Explicitly untouched
- server/index.js
- server/package.json
- server/.env
- src/supabase.js
- Supabase schema
- Razorpay configuration and payment API
- Storage/download implementation
- Admin portal functionality
- Authentication logic
- Cart UUID/payment data flow

No sample data was added.
