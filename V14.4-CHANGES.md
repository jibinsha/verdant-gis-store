# V14.4 Performance & Map Explorer Update

This update preserves the existing Verdant GIS workflow and UI while making only the requested changes.

## Changes
- Dataset cards, category cards and dashboard cards no longer download GeoJSON just to draw a small preview.
- Dataset pages use the uploaded preview image; GeoJSON remains reserved for Map Explorer.
- Admin dataset upload keeps GeoJSON for Map Explorer and provides an optional preview image for fast catalogue/product/dashboard display.
- Map Explorer visualization controls are now passed into the actual GIS map renderer:
  - Single colour
  - Different colours by attribute
  - Graduated colours
  - Attribute field selection
  - Colour palette selection
- Legend and feature styling use the same classification.
- Public catalogue metadata uses a short in-memory cache to reduce repeated Supabase requests.
- Customer dashboard now loads library + order history through one authenticated API request.
- Existing `/api/library` and `/api/my-orders` endpoints remain available for compatibility.
- Dataset metadata fetches use explicit columns instead of `*` where appropriate.

## Intentionally unchanged
Razorpay, cart, authentication, RLS, secure downloads, existing routes, admin workflow, dataset publishing workflow, Map Explorer tools, attribute table, basemaps and overall design are not otherwise changed.
